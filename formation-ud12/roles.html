Étape 2 sur 5

Dans l'entreprise : élu·es et mandaté·es

Comment animer : demandez d'abord « Qui choisit les candidat·es CGT au CSE ? ». Réponse attendue : les syndiqué·es, dans le syndicat. Les salarié·es votent ensuite pour la liste. Puis passez aux cartes.

🗳️ Les élu·es

Les syndiqué·es, dans le syndicat choisissent les candidat·es et construisent la liste CGT Liste CGTreprésentative de tous les collèges les salarié·es votent le CSE désigne parmi ses membres

📜 Les mandaté·es

Le syndicat désigne directement

Tout mandat part du syndicat. Les candidatures aux élections comme les mandats sont décidés par les syndiqué·es. Les élu·es sont ensuite choisi·es par les salarié·es ; les mandaté·es sont désigné·es directement par le syndicat. Toutes et tous rendent compte au syndicat. Charte de l'élu·e et mandaté·e CGT (2025).
